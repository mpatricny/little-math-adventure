# Google account assets

- `google-g.png`: current official mark from
  https://developers.google.com/static/identity/images/g-logo.png
- `google-sans-latin.woff2` and `google-sans-latin-ext.woff2`: Google Sans Medium
  from the Google Fonts CSS API, Latin subsets only. License: `GoogleSans-OFL.txt`.

Downloaded 22 September 2026. Source guidance:
https://developers.google.com/identity/branding-guidelines

The provider button uses the original color mark, a white surface, local font
files, and runtime Czech labels. Its images and fonts make no requests to Google
while the game is loading.
