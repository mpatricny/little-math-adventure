# Silverpond Enemy Forms

Generated non-destructively with the built-in ImageGen tool. Each corresponding
pet-form PNG in the parent directory was used as the sole edit target.

## Shared edit prompt

```text
Use case: identity-preserve
Asset type: enemy-form variant of an existing 2D game creature
Input images: Image 1 is the sole edit target and the canonical pet-form design.
Primary request: Transform the exact same creature into a temporarily corrupted,
confused-aggressive Silverpond arena enemy. It must look alarmed, disoriented,
defensive, and ready to attack rather than evil or gleeful. Make the emotion
readable at battle-sprite size through asymmetrical furrowed brows, tense posture,
slightly mismatched gaze, and restrained violet Numera corruption.
Corruption language: a few jagged violet-magenta crystal splinters, thin glowing
purple vein cracks, and compact unstable purple energy close to the body. The
corruption must look removable after defeat.
Style/medium: preserve the exact polished hand-painted 2D cartoon rendering,
crisp outlines, eye treatment, materials, and child-friendly style of Image 1.
Scene/backdrop: genuinely transparent background with preserved alpha; no floor,
scenery, vignette, cast shadow, or checkerboard pattern.
Critical invariants: this is a variant, not a redesign. Preserve the same species,
signature silhouette, anatomy, proportions, colors, armor, jewelry, crystals,
water elements, camera view, facing direction, overall scale, and full-body framing.
Avoid: friendly smile, calm pet pose, sad expression, comedy, demonic redesign,
red skin, horns, fire, blood, gore, wounds, skulls, extra limbs, characters, props,
text, labels, border, UI, logo, watermark, scene, sprite sheet, or alternate views.
```
