# Silverpond Guild Notification

Use case: stylized-concept

Asset type: isolated production UI notification marker state pair for the Silverpond town hub in a children's fantasy game

Primary request: Create exactly two copies of the same small empty notification medallion side by side in equal square cells. The left copy is the normal state; the right copy is the active state. The medallion is a compact polished silver-and-bronze circular frame with a dark deep-teal enamel center, a tiny violet-blue crystal finial at the top, and subtle aquatic wave engraving. Leave the center completely empty for a runtime exclamation mark.

Match the supplied game's warm hand-painted fantasy UI language and preserve one shared visual system. Create only the requested isolated icon pair; do not add text. For this state pair, generate both states together with identical silhouette, pose, scale, cell size, and placement. Change only light, glow, or compact particles.

Normal state: softly lit metal and crystal, readable but restrained.

Active state: identical medallion geometry and placement; add only a bright cyan-lavender crystal glow, a thin illuminated rim, and three or four compact spark particles close to the frame.

Composition: one horizontal two-cell sheet, left normal and right active, equal square cells, both medallions front-facing, perfectly centered, same apparent size, generous clear padding, nothing cropped.

Background: perfectly flat solid `#00ff00` chroma-key background with no cast shadow, ambient scenery, gradient, texture, reflection, floor plane, or lighting variation. Do not use `#00ff00` anywhere in either medallion.

Constraints: no text, no letters, no exclamation mark, no numbers, no logo, no watermark. The result will be chroma-keyed, split at the exact sheet midpoint with one shared crop, centered on identical transparent canvases, and composed with runtime text and code-driven interaction. Do not change the frame silhouette, scale, pose, or placement between states.

Avoid: red warning badge, modern app icon, flat vector style, giant glow cloud, different ornaments between states, tilted perspective, mismatched sizes, embedded text, shadows on the green background.
