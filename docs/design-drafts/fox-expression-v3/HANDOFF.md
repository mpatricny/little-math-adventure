# Runová liška — úprava výrazu V3

19. listopadu 2026. Jeden statický návrh vycházející z původní detailní
ilustrace `../training-flow-v5/assets/fox-reward.webp`. Autor jej po zobrazení
přijal jako lepší směr slovy „jo, tahle je lepší“.

## Rozsah

- Zachovat původní anatomii, proporce, pózu, oranžovou srst a detailní runy.
- Změnit přísný výraz na vlídnější: uvolněné obočí, otevřený pohled, jemný úsměv.
- V2 nová postava i její evoluce jsou odmítnuté a nesmějí se integrovat.
- Tento návrh je základem pro další podoby; nové evoluce dosud nejsou schválené.
- Nové animace počkají na schválení podob. Stávající produkční bojová animace
  a sdílená textura nepřítele/mazlíčka se nemění.

## Podklady

- [Srovnání](http://localhost:8013/docs/design-drafts/fox-expression-v3/index.html)
- `assets/fox-friendly.png`: výstup built-in image_gen, zachovaná alfa.
- `assets/prompt.json`: přesné zadání, původní předloha a cesta generovaného zdroje.

Jde o generovaný edit, nikoli o pixelově totožnou rekonstrukci: rozhodující je
zachování původní kresby a postavy. Není to spritesheet ani produkční animace.
Galerie nabízí stejný výřez obličeje a tmavé/světlé pozadí pro porovnání.
Pouze výtvarná revize mimo hráčské UI; žádná herní pravidla, API ani ukládání.
Standalone Vite na 8013 nemá závislost na databázi nebo migracích.

## Následná oprava póz

Autor následně výslovně požádal o různé postoje u jednotlivých podob, aby
liška působila živěji. Shodná póza zde slouží pouze srovnání výrazu; pro
další statické podoby se zachovává identita a styl, nikoli přesný postoj.
